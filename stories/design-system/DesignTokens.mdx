# Design Tokens

Alle visuellen Grundwerte der kenalu-Website sind als CSS Custom Properties in `app/globals.css` definiert. Sie sind in allen Komponenten über `var(--name)` verfügbar.

## Typografie

Fonts werden via `app/layout.js` geladen: **Satoshi** (Fontshare CDN) für Headlines, **Inter** (Google Fonts / Next.js) für Fliesstext.

```css
--font-headline: 'Satoshi', 'Inter', sans-serif;
--font-body:     'Inter', sans-serif;
```

| Token | Wert | Verwendung |
|---|---|---|
| `--font-headline` | Satoshi, Inter | `h1`–`h4`, Hero, Eyebrow |
| `--font-body` | Inter | Fliesstext, Labels, UI |

## Spacing & Layout

```css
--max-width:  1120px   /* maximale Content-Breite */
--gutter:     2rem     /* seitliche Abstände (mobile: 1.25rem) */
```

Der Container-Pattern:
```css
.container          { max-width: var(--max-width); margin-inline: auto; padding-inline: var(--gutter); }
.container--narrow  { max-width: 720px; }
.container--wide    { max-width: 1300px; }
```

## Interaktions-Tokens

```css
--radius:     6px        /* Standard-Border-Radius */

```

---

## Verwendung in Komponenten

```css
/* Korrekt: CSS Custom Property */
background: var(--ivory);
color: var(--charcoal);
border-color: var(--mineral);

/* Korrekt: Fallback angeben bei externen Komponenten */
color: var(--stone, #686E72);
```

> **Tailwind 4 und Custom Properties:** Tailwind ist konfiguriert, aber Design Tokens werden als CSS Custom Properties gepflegt – nicht als Tailwind-Config-Werte. Klassen wie `bg-ivory` existieren nicht; stattdessen `style={{ background: 'var(--ivory)' }}` oder eine CSS-Klasse mit `background: var(--ivory)`.
