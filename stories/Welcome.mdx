# kenalu – Component Library & Dokumentation

Dieses Storybook dokumentiert die Komponenten, das Design System und die technische Architektur der [kenalu-Website](https://kenalu.ch).

## Was ist hier drin?

| Bereich | Inhalt |
|---|---|
| **Design System** | Design Tokens (Farben, Fonts, Spacing), CSS-Konventionen |
| **Components** | Alle wiederverwendbaren Komponenten mit Varianten und Props |
| **Architektur** | Projektstruktur, Storyblok-Schema, API Routes |

## Technischer Stack

- **Framework:** Next.js 16 (App Router)
- **CMS:** Storyblok (Space: kenalu, ID: 293099469334951)
- **KI:** Kai via OpenAI gpt-4o-mini (`/api/kai`)
- **Styling:** Tailwind 4 + CSS Custom Properties

## Lokale Entwicklung

```bash
# Next.js Dev-Server
npm run dev

# Storybook
npm run storybook
```

## Sprachliche Konventionen

- Anrede: **ihr/euch/euer** (nie du, nie Sie)
- Sprache: Deutsch, Schweizer Schriftsprache (kein ß, immer ss)
- Ton: klar, menschlich, eigenständig
